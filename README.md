# Boo Pop TD (web build)

Boo Pop TD: pop candy-coloured sheet ghosts before the lanterns go out. A 3D tower defence by perhapsJohn, made in Godot.

This repository holds only the web export that GitHub Pages serves at
https://perhapsjohn.github.io/BooPopTD/ (played in the Wayside Station arcade).
Phones load `index.mobile.pck`, desktop browsers `index.pck`. The source lives elsewhere.
